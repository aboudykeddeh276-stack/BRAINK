# V98 Compliance Pack

## Position

This pack is a compliance-control and evidence-readiness package. It is not a certificate.

## Included frameworks

- ISO/IEC/IEEE 12207:2026 software lifecycle alignment
- ISO/IEC 42001:2023 AI management-system alignment
- ISO/IEC 27001:2022 and 27002:2022 information-security control alignment
- ISO/IEC 27018:2025 cloud PII processing alignment
- ISO/IEC 23894:2023 AI risk-management alignment
- ISO/IEC 25010:2023 software quality model alignment
- NIST CSF 2.0 and NIST SSDF 1.1 secure-development alignment
- OWASP SAMM and ASVS software assurance/security verification alignment
- SLSA and CycloneDX SBOM/provenance alignment
- POSIX.1-2024 target-host gate alignment
- MISRA C:2012 and DO-178C external assurance gates

## Required distinction

Reference alignment proves that a control is mapped and managed. It does not prove accredited certification, production security, hardware qualification, or aviation assurance.

## Evidence hierarchy

1. Executed behavior
2. Positive test
3. Negative-space falsifier
4. Ledger write and readback
5. Outbox handoff
6. Target-host or provider receipt where required
7. External certificate where external certification is claimed

Hashes and signatures support custody and tamper detection; they are not standalone functional proof.
