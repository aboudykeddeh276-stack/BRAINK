# Mirror Update Lane Compliance Crosswalk

## Purpose

This crosswalk binds the mirror update lane to explicit frameworks without converting framework references into certification claims.

| Domain | Framework / Standard | Mirror-lane control |
| --- | --- | --- |
| R&D / innovation | ISO 56001:2024 | Mirror lane maintains innovation work products, R&D rationale, implementation path and improvement loop. |
| Software lifecycle | ISO/IEC/IEEE 12207:2026 | Mirror lane records requirements, implementation, verification, operation and maintenance controls. |
| AI governance | ISO/IEC 42001:2023 | Mirror lane separates AI/coding-agent implementation authority from acceptance authority. |
| AI risk | ISO/IEC 23894:2023 | Mirror lane maps provider, target-host and certification uncertainty as explicit risk gates. |
| Security management | ISO/IEC 27001:2022 / 27002:2022 | Mirror lane preserves security controls for secrets, logs, access boundaries and receipt custody. |
| Privacy/cloud | ISO/IEC 27018:2025 | Mirror lane blocks hidden Drive/provider transit claims without receipts. |
| Secure SDLC | NIST SSDF 1.1 | Mirror lane requires structured development, negative-space testing and evidence output. |
| Cybersecurity risk | NIST CSF 2.0 | Mirror lane identifies, protects, detects, responds and recovers through control records and gates. |
| AppSec verification | OWASP ASVS | Mirror lane expresses requirements as verifiable application-security controls. |
| Assurance maturity | OWASP SAMM | Mirror lane turns ad hoc procedures into governed assurance activities. |
| Supply-chain integrity | SLSA | Mirror lane uses PRs, workflow evidence, outbox handoffs and provenance-ready custody metadata. |
| BOM/SBOM | CycloneDX / ECMA-424 | Mirror lane prepares component and artifact metadata for BOM/SBOM packaging. |
| Target-host interface | POSIX.1-2024 | Mirror lane preserves POSIX/macOS target-host claims as executable receipt gates. |
| Safety-critical coding | MISRA C:2012 / DO-178C | Mirror lane treats these as external/qualified-toolchain gates only. |

## Compliance boundary

The mirror lane is a control and evidence-readiness structure. It does not produce accredited certification by itself.
