# KEX topology-native control

Preserves the reconstructed logical-object and carrier topology.

Source reconciliation: 76 logical objects, 95 unique carrier IDs, 19 genuine multi-carrier logical objects, 33 R5 high-level named identities, and 23 R5/P11 overlaps.

The controller binds logical identity to implementation carrier, observed evidence, and justified claim.

Evidence levels: DECLARED, RESOLVED, IMPLEMENTED, EXECUTED, READBACK_VERIFIED, EXTERNALLY_PROVEN.

This is an evidence and readback mechanism. It does not impose funding, procurement, vendor, or strategic restrictions. Development remains possible; unsupported execution or proof claims are not promoted beyond recorded evidence.
