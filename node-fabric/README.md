# BRAINK × KEX Node Fabric

Executable reusable-node substrate.

A template preserves stable definition, typed I/O, semantic class, attributes, attribution, capability contracts, integration contracts, state schema and observer contract. Instantiation creates independent state, observer, VFS, runtime, network identity and lineage.

## API
GET /health /graph /templates /instances
POST /instantiate /connect /state

Run: python3 runtime_server.py --host 127.0.0.1 --port 8791

The runtime is provider-neutral. Existing BRAINK/KEX systems are integrated as templates rather than copied markup.
