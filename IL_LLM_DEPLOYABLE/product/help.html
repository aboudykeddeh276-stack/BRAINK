Operation lifecycle

  1. State the objective.
  2. Resolve local evidence and capability.
  3. Apply admission and authority gates.
  4. Execute only the qualified function.
  5. Read back the result.
  6. Record evidence and qualification state.

Common states

UNKNOWN
The property has not been established from the current route.
WAITING
A known dependency has not yet produced required evidence.
BLOCKED
A required governance, authority or admission predicate failed.
DEGRADED
The function is available but a qualified dependency is impaired.
ERROR
An attempted operation failed; inspect the operation receipt.
DONE
Only the named operation/property completed. It does not promote unrelated properties.

Escalation packet

When requesting assistance retain: objective, timestamp, function name, runtime version, operation/packet hash, evidence paths, state, error code, expected result and actual result. Do not include secrets in support packets.
