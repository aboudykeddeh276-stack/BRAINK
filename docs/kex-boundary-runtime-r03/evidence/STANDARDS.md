# Standards basis

Linux kernel ublk documentation: userspace block-device framework; /dev/ublkb* is supplied by the kernel ublk driver and userspace handles block-device logic.

Linux kernel NBD documentation: a client can use a remote userspace server as a block device.

W3C WebAssembly Core Specification: current 2026 Candidate Recommendation Draft defines a low-level binary format/virtual ISA with validation and execution semantics.

IETF RFC 2119 / BCP 14: normative requirement keywords provide a disciplined vocabulary for protocol requirements.

These standards validate interfaces/patterns, not KEX-specific semantics.
