# R03 Boundary Protocol

Forward: semantic identity -> KEX definition -> coordinate resolution -> instance -> HTML projection OR binary encoding -> substrate.

Reverse: substrate bytes -> binary decode -> KEX reconstruction -> semantic resolution -> projection.

MUST invariants: definition identity remains immutable during instantiation; instances receive independent state/observer/attribution; conflicting coordinate registrations are rejected; Layer-2 reconciliation does not overwrite canonical definitions; undeclared ToT actions are rejected; malformed/non-canonical codec input is rejected.

GitHub is not a runtime dependency. The package is executable from a filesystem with Python 3 and a browser.
