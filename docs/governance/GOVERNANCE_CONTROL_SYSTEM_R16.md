# BRAINK Governance Control System R16

R16 is the reusable governance substrate for every BRAINK/KEX sector, module, function, service, agent, domain, runtime and workflow.

Invariant: `IDENTITY → AUTHORITY → PURPOSE → PROCESS → MUTATION → EVIDENCE → VERIFICATION → READBACK → RECEIPT → ACCOUNTABILITY`.

Every governed unit defines identity, parent, sector, owner, author, authority, purpose, runtime boundary, proof condition, supported platforms, process lifecycle, workflow gates, administration, help, filing root, revision policy, rollback and receipts.

Promotion law: `S = COMPLETE iff V ⊨ R`. Unknown stays UNKNOWN. Blocked external authority stays BLOCKED.

Control hierarchy: Authored protocol → invariant → deterministic function → implementation → adapter → operator → evidence → readback → promotion.

Cross-adaptation: `Skeleton + Unit Control + Sector Adapter + Platform Adapter = Governed Implementation`.

Required unit files: CONTROL.md, PROCESS.md, WORKFLOW.md, RUNBOOK.md, ADMIN.md, HELP.md, ACCOUNTABILITY.md, ADAPTATION.md, unit.control.json, MANIFEST.sha256.json.
