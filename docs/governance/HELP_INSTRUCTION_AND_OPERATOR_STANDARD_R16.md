# Help, Instruction and Operator Standard R16

Every governed unit documents: purpose, prerequisites, supported inputs, expected outputs, normal operating procedure, examples, state model, warnings and irreversible actions, known failure conditions, troubleshooting, recovery/rollback, escalation owner, administration entry points and evidence/readback location.

User assistance, operator instructions and administrator instructions are separate surfaces.

Help text must distinguish conceptual capability, implemented capability and current observed state. A user-facing guide must never claim a deployment or external authority that the operator/runbook evidence does not support.
