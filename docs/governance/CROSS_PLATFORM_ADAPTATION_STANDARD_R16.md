# Cross-Platform Adaptation Standard R16

Canonical BRAINK/KEX semantic identity and governance remain stable across platforms.

`Canonical Unit → Semantic Contract → Platform Adapter → Native API/ABI/Runtime → Readback`.

Each adapter declares: adapter ID/version, target platform, native dependencies, API/ABI boundary, filesystem/storage boundary, networking boundary, identity/auth boundary, capability differences, unsupported functions, translation rules, proof tests and rollback/uninstall method.

Designed adaptation classes include macOS, Linux, Windows, browser/Web, workbook/Sheets, mobile, containers/VMs, cloud/edge, local/mesh, registrar/DNS/TLS providers, databases/storage engines and sector-specific business systems.

Platform convenience must never silently redefine canonical identity, lineage, authority, proof conditions or filing rules.
