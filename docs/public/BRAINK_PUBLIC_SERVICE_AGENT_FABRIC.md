# BRAINK Public Service Agent Fabric

`WHOLE_BRAINK_PUBLIC_SERVICE_AGENT_FABRIC` assigns the resident BRAINK agent family across the public-service lifecycle for `braink.com.au`, `braink-intelligence.com.au`, and `braink-learning.com.au`.

The governed functions cover service provisioning, sales, Stripe checkout, Google OAuth, onboarding, customer sessions, product usage, customer service, billing and entitlements, R&D, HTTPS, certificates, DNS/domain authority, corporate/ABN authority, authorship/provenance, legal disclosures, privacy/data governance, standards/certification, professional landing-page publication, release publication, independent public readback, observability, telemetry, incident recovery, and security response.

Corporate identity is resolved at execution time through `FUNCTION_CORPORATE_ABN_AUTHORITY`; the agent source does not freeze registry identifiers. Provider credentials remain inside their owning server processes.

Execution law: `AUTHORITY -> ACTION -> EVIDENCE -> READBACK -> PROMOTION`.

Publication chain: `CORPUS -> DEFINITIONS -> AUTHORSHIP/OWNERSHIP -> WORKSPACE/VFS -> SERVER ROOM -> LINUX/AI RUNTIME -> AUTH/PAYMENT RAILS -> DNS/TLS/INGRESS -> PUBLICATION -> EXTERNAL READBACK`.
